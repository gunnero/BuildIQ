# MVP Demo Flow

This document describes the local BuildIQ MVP demo flow from login to PDF download.

## Scope

The demo uses local development data created by `buildiq-seed-dev`.

The demo must not be treated as production data or a production credential source. BuildIQ V1 still has no AI, no provider SDKs, no online payments, and no frontend-owned construction, pricing, total, or balance calculations.

## Local Setup

From the repository root:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e './backend[dev]'
cp .env.example .env
docker compose up -d postgres
```

Migrate and seed the backend:

```bash
(cd backend && ../.venv/bin/alembic upgrade head)
(cd backend && ../.venv/bin/buildiq-seed-dev)
```

Start the backend:

```bash
(cd backend && ../.venv/bin/uvicorn app.main:app --reload)
```

Start the frontend in another terminal:

```bash
(cd frontend && npm ci)
(cd frontend && cp .env.example .env)
(cd frontend && npm run dev)
```

## Demo Script

1. Open the frontend local URL shown by Vite.
2. Log in with `owner@demo.buildiq.local` and `ChangeMe123!`.
3. Confirm the dashboard shows the demo company and active subscription.
4. Open `Клиенти`.
5. Select the demo customer and confirm the property is available.
6. Open `Проекти`.
7. Select the demo painting project.
8. Review `Преглед`, `Финансии`, `Простории`, and `Мерења`.
9. In the room section, confirm the room areas are displayed from backend values. The frontend must not calculate room area values.
10. Open `Пресметки`.
11. Select the completed painting calculation.
12. Confirm the calculation detail shows backend output values, assumptions, warnings, and line items.
13. Open `Понуди`.
14. Select the accepted estimate copied from the calculation.
15. Review the revision, item list, and backend totals.
16. Click `Генерирај PDF понуда`.
17. Confirm a generated document appears in the estimate detail.
18. Click `Преземи PDF`.
19. Confirm the downloaded PDF is a Macedonian quote generated by the backend.
20. Open `Уплати` and confirm the demo payment is available.
21. Open `Трошоци` and confirm the demo expense is available.
22. Return to `Проекти` and review the project financial summary.

## Demo Boundaries

- The frontend may display only backend-returned room, calculation, estimate, payment, expense, and financial summary values.
- PDF generation must happen only through `POST /api/v1/estimates/{estimate_id}/pdf`.
- PDF download must happen only through `GET /api/v1/estimate-documents/{document_id}/download`.
- The frontend must not generate PDF files.
- The frontend must not calculate estimate totals, PDF totals, payment totals, balances, or project profit.
- Future AI features remain outside V1 and must integrate only through Kalveri OS.
