# Project Overview

BuildIQ is a Macedonian-first construction calculator and project/payment management platform.

## Purpose

The product helps construction teams and small contractors move from room measurements to material calculations, estimates, payments, expenses, and Macedonian PDF offers.

## V1 Product Position

BuildIQ V1 is standalone. It is not OneFiveFour OS and must not depend on OneFiveFour OS for core construction workflows.

V1 includes no AI features.

## Primary Users

- Construction business owners
- Project managers
- Estimators
- Employees who enter measurements, payments, and expenses

## Core Workflow

1. A user logs in.
2. The user creates a customer.
3. The user creates a project for that customer.
4. The user adds one or more rooms.
5. The user enters room dimensions.
6. The user runs construction calculations.
7. The user generates an estimate.
8. The user records payments.
9. The user sees how much the customer has paid.
10. The user sees how much the customer still owes.
11. The user generates a Macedonian PDF offer/quote.

## V1 Success Criteria

- Users can manage customers, projects, rooms, measurements, calculations, estimates, payments, and expenses.
- Users can track agreed project price, total paid, and remaining balance.
- Users can generate Macedonian PDF offers/quotes.
- All user-facing text is Macedonian.
- All code, database objects, API routes, and documentation are English.
- No direct AI or LLM provider integration exists in the V1 codebase.

## V1 Non-Goals

- AI assistants
- Direct OpenAI, Anthropic, Gemini, or other provider integration
- Multi-product OneFiveFour OS architecture
- Complex enterprise procurement
- Payroll
- Inventory warehouse management
- Accounting system replacement
