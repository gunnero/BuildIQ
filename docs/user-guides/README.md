# BuildIQ User Guides

This folder contains user-facing BuildIQ guides.

- `buildiq-user-guide-mk.md` - Macedonian user guide for BuildIQ v0.9 RC1.
- `buildiq-user-guide-mk.pdf` - PDF version of the Macedonian user guide.

The Macedonian guide is written for test users and construction teams. It must not include production secrets or production passwords.
